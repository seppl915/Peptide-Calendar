        Sync zwischen Geräten

        Deine Daten werden Ende-zu-Ende-verschlüsselt über einen Sync-Server abgeglichen. Der Server kann die Inhalte nicht lesen. Alle Geräte brauchen denselben Sync-Schlüssel.

        Sync-Schlüssel – auf dem anderen Gerät unter „Mit Schlüssel verbinden“ eingeben:

        Server:

        Bewahre den Schlüssel sicher auf – wer ihn kennt, kann deine Daten lesen.

        Daten

        Ohne Sync werden alle Daten nur lokal auf diesem Gerät gespeichert.
